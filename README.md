# Personal-Website
**This is a personal/professional website about me.** It is created with HTML and CSS programming, and currently displays the following components:
  - A personal description
  - A project portfolio
  - My downloadable, up-to-date resume
  - Contact Information
  - Feedback/Communication Section

## Current Status
- This is a website that is hosted using Firebase hosting
- Authentication and feedback functionalities have been added!

## Security & Networking Features
- ✅ DNS Handling: Resolving the domain to an IP address
- ✅ IP Addressing: Hosted on Firebase's infrastructure
- ✅ HTTPS Encryption: Secured using SSL/TLS certificates
- ✅ Networking Protocols: Studying & implementing HTTP, DNS, and more
- ✅ SQL & XSS Attack Protection: Sanitzes user input with DOMPurify
- ✅ Brute-Force Login Protection: Preventing request overloads and abusive behavior from user with a Rate Limiter
- ✅ Cookies & CSRF Protection: Using a CORS config and Cookie Parser

## Technologies Used
- 🔧 HTML/CSS, JavaScript - For the UI and client-side scripting of the website
- 🔥 Google Firebase - For the backend database storage and hosting of the site
- 🔒 Cybersecurity Practices  - HTTPS, DNS, IP handling
- 💾 Backend Integration - Firebase Firestore Database, User Authentication Storage, and Dynamic Feedback Integration
